# UNICA — AI Creative Suite (Beta 1.1)

Immagini, musica e video generati con l'intelligenza artificiale **sul tuo PC**. Gratuita, senza cloud e senza abbonamenti.

**Sito e download:** https://umbertomaravigna61-debug.github.io/unica/

- Setup: `UNICA-Setup-1.1.0-beta.exe` (160 MB, Windows 64 bit), nella pagina [Releases](https://github.com/umbertomaravigna61-debug/unica/releases)
- SHA-256: `a4afc077d043ba1e1368f13e94cc11283d06c011c377708d274ce11289f3dea6`
- Motori: YuE2-3B per la musica cantata (predefinito dalla 1.1; ACE-Step 1.5 come alternativa), FLUX.2-klein per le immagini, LTX-2.5 per i video
- Requisiti: Windows 11 64 bit, scheda NVIDIA con CUDA (provato su 8 GB), disco NTFS
