SERVIZI REMOTI OPZIONALI
UNICA funziona interamente in locale. Gli assistenti AI esterni (tramite Agent Bridge) e il provider LLM remoto opzionale
(es. Cloudflare Workers AI) si usano solo per scelta esplicita dell'utente, con il proprio account e alle condizioni del fornitore.
UNICA non contiene credenziali, Account ID o chiavi API di alcun servizio.
